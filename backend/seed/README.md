# 샘플 데이터

이 폴더의 파일은 **가상의 샘플 데이터**입니다. 공고번호·기관·업체·금액은 실제 입찰과 관계없으며,
업로드 기능과 분석 화면을 시험하기 위한 용도로만 사용하세요. 실제 분석에는 공식 데이터나
사용자가 보유한 자료를 사용해야 합니다.

- `sample_results.csv` — 개찰 결과가 포함된 공고 목록(UTF-8). 일부 행에 의도적인 오류·경고가 있습니다.
  - 7행: 존재하지 않는 날짜(2024-02-30)
  - 8행: 4행과 공고번호·차수 중복
  - 9행: 개찰 결과 미확인(결과 없음)
- `sample_history.csv` — 가상의 과거 개찰 결과 240건(2023-11~2026-10). `generate_sample_history.py` 로 다시 만들 수 있습니다.
  올릴 때 낙찰률 기준은 "예정가격"으로 지정하세요.

## sample_notice.pdf

`generate_sample_notice_pdf.py` 로 만든 가상 공고문 PDF(2쪽)입니다. 실제 공고가 아닙니다.
PDF 분석 화면(`POST /api/pdfs`)에서 항목 추출·검토·반영을 확인할 때 씁니다.
공고번호·공고명·기관·기초금액·추정가격·낙찰하한율(1·2쪽 모두)·A값·마감/개찰일시·계약방법·결정방법·예비가격 범위·부가세 포함 문구·참가자격(표)·지역제한(2쪽)이 들어 있습니다.
