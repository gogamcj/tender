# 엑셀·CSV 업로드 안내

보유한 입찰공고·개찰결과 자료(XLSX, XLS, CSV)를 시스템에 올리는 방법입니다.

## 지원 형식
- XLSX(권장), XLS(구형 엑셀), CSV(UTF-8 또는 CP949/EUC-KR, 쉼표·탭·세미콜론 구분 자동 인식)
- 최대 20MB, 10만 행. 매크로가 포함된 파일은 거부합니다.
- 첫 행이 헤더가 아니면 `header_row`(0부터 세는 헤더 행 번호)를 지정합니다.

## 절차 (API 기준, 화면은 7단계에서 제공)
1. **파일 업로드** `POST /api/imports` (multipart `file`) → 시트 목록, 열 이름, 처음 5행, 자동 추천 매핑을 돌려줍니다.
   같은 파일을 전에 저장한 적이 있으면 경고합니다.
2. **열 매핑·미리보기** `POST /api/imports/{id}/preview`
   ```json
   {"sheet_name": "결과",
    "mapping": {"notice_number": "공고번호", "title": "공고명", "base_amount": "기초금액(원)", "winning_rate": "낙찰률"},
    "options": {"rate_unit": "percent", "default_winning_rate_basis": "estimated_price",
                "issuing_authority_type": "local", "procurement_type": "construction"}}
   ```
   - 자동 추천은 열 이름이 정확히 일치할 때만 붙습니다. `기초금액(천원)`처럼 단위가 다른 열은 추천하지 않으니 직접 확인하세요.
   - 필수 열: 공고번호, 공고명. 낙찰률을 올리려면 **낙찰률 기준**(예정가격/기초금액/추정가격) 열이나 기본값이 반드시 있어야 합니다.
   - 결과로 행마다 상태(`new`, `new_revision`, `unchanged`, `changed`, `duplicate_in_file`, `invalid`), 오류, 경고, 기존 값과의 차이(변경 전 → 후)를 보여 줍니다.
3. **확정 저장** `POST /api/imports/{id}/commit` `{"accept_changes": [행번호...], "skip_rows": [행번호...]}`
   - 새 공고와 새 차수만 자동으로 저장합니다.
   - 기존 데이터와 값이 다른 행은 `accept_changes`에 행 번호를 넣은 경우에만 반영하며, 필드별 변경 전후를 이력에 남깁니다.
   - 오류 행과 중복 행은 저장하지 않습니다.
4. **결과 보고서** `GET /api/imports/{id}/report.csv` (엑셀에서 바로 열리는 UTF-8 BOM CSV)
5. **되돌리기** `POST /api/imports/{id}/rollback` — 이 작업이 만든 공고·결과를 지우고, 반영한 변경을 이전 값으로 되돌립니다.

## 값 변환 규칙
| 종류 | 허용 예 | 거부 예 |
|---|---|---|
| 금액 | `1,234,567` `1234567원` `₩1,000` | `1.2억` `3천만`(단위 표기), 음수, 원 미만 |
| 비율 | `87.745` `87.745%`, 소수 단위 지정 시 `0.87745` | 문자, 소수 6자리 초과 |
| 날짜 | `2024-03-04` `2024.03.04` `2024/3/4` `20240304` `2024년 3월 4일` | `2024-02-30`(존재하지 않는 날짜) |
| 일시 | 위 날짜 + `11:00`, 나라장터 형식 `202403201100` | `25:00` |

- 시간대 표기가 없는 일시는 한국 표준시(KST)로 보고 UTC 로 저장합니다.
- 비율 단위가 의심스러우면(예: 퍼센트 설정인데 0.87) 경고합니다. 자동으로 바꾸지 않습니다.

## 상태 판정
- 개찰 결과가 있으면 예정가격을 **실제 확정값**으로, 없으면 **사용자 가정값**으로 저장합니다.
- 개찰일이 지났는데 결과가 없으면 "개찰 결과 미확인"으로 표시합니다. 유찰로 간주하지 않습니다.
- 결과 열은 있지만 개찰 상태 열이 없으면 낙찰자 정보가 있을 때만 "낙찰자 결정"으로 봅니다.
- 기초금액·공고일이 비어 있으면 "일부 항목 누락"으로 표시합니다.
- 사정률이 ±10%를 넘거나 낙찰률이 낙찰금액÷기준금액 계산값과 0.001%p 넘게 다르면 경고합니다(오류 아님).

## 중복 판단
- 같은 파일 안: 공고번호+차수가 같은 두 번째 행부터 건너뜁니다.
- 기존 데이터: 출처와 상관없이 공고번호+차수가 같으면 같은 공고로 보고, 값을 비교합니다.
- 같은 공고번호의 다른 차수는 새 차수로 저장하고 가장 큰 차수를 최신으로 표시합니다.

## 원본 보존
업로드한 파일은 `BID_STORAGE_DIR/uploads/<sha256>.<확장자>`에 그대로 보관하고, 저장된 행마다 원본 셀 값을 `notice_raw_records`에 남깁니다.

## 샘플
