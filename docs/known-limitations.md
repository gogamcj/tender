# 알려진 제한사항

이 문서는 단계가 진행될 때마다 갱신합니다. (최종 갱신: 1단계, 2026-10-27)

## 규칙·산식
- 낙찰하한율, 금액 구간, 복수예비가격(개수·범위·추첨) 규칙, 적격심사 배점은 아직 원문 예규와 대조해 등록한 것이 없습니다. 규칙은 사용자가 등록하며 기본 상태는 "미검증"입니다.
- 계산 엔진 테스트의 기대값은 독립 계산(분수 연산)과 수기 검산으로 만든 것입니다. 실제 공고문·공식 예시와의 교차 검증은 아직 하지 못했습니다.
- 금액 처리(절사·반올림) 규칙이 등록되지 않은 경우 원 미만 값을 그대로 표시하고 경고합니다. 임의의 법정 처리 규칙을 적용하지 않습니다.
- 부가가치세 기본 세율 10%는 계산 입력의 기본값일 뿐이며, 공고에 세액이 명시되면 명시값을 우선합니다.

## 데이터베이스
- SQLite(개발용)에서는 금액·비율을 스케일된 정수로 저장합니다. SQLite 에서 SQL 로 직접 SUM/AVG 를 하면 스케일된 값이 나오므로, 통계는 애플리케이션 계층에서 계산합니다. 운영은 PostgreSQL 을 권장합니다.
- 금액 컬럼은 정해진 소수 자릿수를 넘는 값을 저장 단계에서 거부합니다(몰래 반올림하지 않음).

## 외부 API
- 개발 환경에서 data.go.kr 접속이 차단되어 있어, 나라장터 API 의 실제 응답 필드는 아직 확인하지 못했습니다(3단계에서 가짜 응답으로 테스트하고 사용자 환경에서 검증).
